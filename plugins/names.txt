# dshPlugins 镜像清单(vimPlugins 的 vim-plugin-names 同构)
# 格式:每行一个插件:owner/repo [subpath] [face=名] [roster=bool]
#   - 注释行(#)与空行忽略
#   - subpath:monorepo 插件取仓库内子目录(awesome 列表的 #path 条目)
#   - face=名:交互面插件标记(收录时人审 —— 互斥语义无法自动推导,
#     见 lib/faces.nix 注释);用户 enable 即自动生成 face profile
#   - roster=bool:face 树是否带 base agent-presets 行(roster 舞资格,
#     收录时探测 bundle patch 的 insert 行;缺省 = 无元数据,消费侧
#     缺省 true)
# 版本由 update.py 解析(tag 优先,无 tag 钉默认分支 HEAD),hash 自动 prefetch,
# 生成 generated.nix → pkgs.dshPlugins.<packageName>(见 overlay.nix)
# 更新:nix run .#dsh-plugins-update(或 GitHub Actions 周期 PR)
#
